# library
灯库仓库

## Modus 灯库数据分发

本仓库仅维护灯库更新资料和维护工具，不包含 Modus 软件源码、Show、账号凭证或研究样本。

- 下载数据请使用 [Releases](https://github.com/wu271861748-jpg/library/releases)。
- Modus 从最新正式 Release 读取 catalog.json，并按厂家下载变更包到本地缓存；用户不需要登录 GitHub。
- 下载成功后可离线浏览与另存 XML / XMLP 原文件，不自动导入控台。
- 普通访问者可以查看、下载或 Fork；修改原仓库仍需维护者写入权限。

维护说明见 [MAINTENANCE.md](MAINTENANCE.md)。灯库原文件保留其原始来源和权利归属；索引解析结果不是全部模式的实机兼容承诺。
