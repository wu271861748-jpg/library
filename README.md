# library
灯库仓库

## Modus 灯库数据分发

本仓库只维护以后新增／修改的灯库及维护工具，不备份现有本地库，不包含 Modus 软件源码、Show、账号凭证或研究样本。

- 上传更新：把新文件放进 `fixtures/`（支持厂家子文件夹），Commit → Push；GitHub Actions 自动发布纯元数据目录，不打厂家整包。
- Modus 点击“更新目录”只读取 `updates/catalog.json`，新厂家/型号/模式立即可搜索，尚未下载的条目标记在线来源；用户不需要登录 GitHub。
- 确认使用/另存时仅下载选中的 XML / XMLP，大小与 SHA256 校验后本地缓存，之后离线可用；不自动导入控台。
- 普通访问者可以查看、下载或 Fork；修改原仓库仍需维护者写入权限。

维护说明见 [MAINTENANCE.md](MAINTENANCE.md)。灯库原文件保留其原始来源和权利归属；索引解析结果不是全部模式的实机兼容承诺。
